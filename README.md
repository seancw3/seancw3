## Stuff I've built

### Floor Plan Mapper - Innovation for Impact/MaizeBus
A PySide6 desktop tool that takes PDF floor plans and turns them into interactive maps with persistent data. Uses DFS-based polygon detection to find room boundaries on its own, so nobody has to trace 600+ campus buildings by hand. Maps export to JSON (typed nodes, usually 200+ per building) so they can be edited later or loaded straight into the MaizeBus app.

`Python` `PySide6` `PyMuPDF`
[https://github.com/cheeto734/maizebuspdf](#) 

### ASL Translator - Michigan Data Science Team
Built to read hand landmarks from a webcam feed and translate continuous ASL into English. Works on an LSTM trained on 40+ gloss classes across 50 epochs for various training on different parameters and setups to see what caused underfitting and overfitting. Across manual, local test runs, about 72% of test runs came out accurate.

`PyTorch` `MediaPipe` `Streamlit` `NumPy` `Pandas`
[https://github.com/Chandelb/W26-Sign-Language-Translator-Group/tree/merged_datasets](#)

### Beat the Buffet - NYU EEG × Vercel hackathon
Take a photo of your sushi, and it counts the pieces, looks up localized ingredient prices through Google Shopping, and tells you if you came out ahead at the buffet. Most of the backend work was cleaning up messy listings: converting everything to $/oz or $/count and using medians so one weird price doesn't throw off the estimate.

`Python` `FastAPI` `Serper API`
[https://github.com/ahanqiliu903/beat-the-buffet](#)
